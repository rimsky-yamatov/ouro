# Ouro 言語仕様書 v0.1

Ouro(ウロ)は、**自分自身をコンパイルできる最小のプログラミング言語**である。
名前はウロボロス(自分の尾を噛む蛇)に由来する。

- ソースファイル拡張子: `.ou`
- コンパイラ: `ouroc`(Ouro で書かれた Ouro コンパイラ)
- 出力: x86-64 Linux 用の静的 ELF 実行ファイル

## 1. 設計目標

1. **セルフホスト可能であること**を唯一の必須要件とする。
2. 言語機能は「コンパイラを書くために必要なもの」だけに絞る。
3. 隠れた動作を持たない。すべての構文が機械語に素直に対応する。
4. コンパイラ本体を 1 人が数日で書き切れる規模に収める(目安: 仕様書は本書程度、`ouroc` は 1,500〜2,500 行)。

### 非目標

型検査、最適化、モジュール、構造体、浮動小数点、例外、ガベージコレクション。

## 2. 字句構造

### 2.1 ソース

- 文字集合は ASCII。バイト列として扱い、非 ASCII バイトは文字列・コメント内でのみ許す。
- 空白(スペース、タブ、改行)はトークンの区切りのみに使い、意味を持たない。
- コメントは `#` から行末まで。

### 2.2 キーワード

```
fn  var  if  else  while  return  break
```

### 2.3 識別子

```
ident = (letter | "_") { letter | digit | "_" }
```

最大 31 文字。キーワードと組み込み関数名は識別子として使えない。

### 2.4 リテラル

| 種類 | 例 | 値 |
|---|---|---|
| 10 進整数 | `42` | その値 |
| 16 進整数 | `0xFF` | その値 |
| 文字 | `'a'` `'\n'` | ASCII コード |
| 文字列 | `"hi\n"` | NUL 終端バイト列の**先頭アドレス** |

エスケープシーケンス: `\n`(10) `\t`(9) `\0`(0) `\\` `\'` `\"`。
文字列リテラルは静的データ領域に置かれ、同一内容でも別領域になってよい。

### 2.5 演算子と区切り

```
+ - * / % & | ^ ~ ! << >> == != < <= > >= && || =
( ) { } [ ] , ;
```

## 3. 型とデータモデル

- 型は **`word` 1 種類のみ**。符号付き 64 ビット整数(2 の補数、オーバーフローは巻き戻し)。
- ポインタ・文字・真偽値もすべて `word`。
- 真偽: `0` が偽、`0` 以外が真。比較・論理演算の結果は `0` または `1`。
- メモリはバイト単位でアドレス指定できる(リトルエンディアン)。

## 4. 宣言

### 4.1 グローバル

```
var counter;        # 8 バイトの word 変数(初期値 0)
var buf[4096];      # 4096 バイトの領域(初期値すべて 0)
```

- `var x;` は word 変数。式中の `x` は値、`x = e;` で代入。
- `var a[N];` は N バイトの静的領域(N は整数リテラル)。式中の `a` はその**先頭アドレス**(定数)で、代入はできない。
- グローバルは使用前に宣言する。

### 4.2 関数

```
fn name(p1, p2, ...) { ... }
```

- 引数はすべて word。最大 8 個。
- 関数は定義の前から呼べる(前方参照可)。
- `return e;` で値を返す。`return;` や末尾到達は `0` を返す。
- 再帰可。オーバーロード不可、関数の再定義はエラー。
- プログラムには `fn main()` が必要。`main` の戻り値がプロセスの終了コード(下位 8 ビット)。

### 4.3 ローカル変数

```
var t;
```

- 関数本体内の任意の位置で宣言できる。スコープは**宣言位置から関数の終わりまで**(ブロックスコープなし)。
- 同一関数内の再宣言、引数名との重複はエラー。ローカルがグローバルを隠すことは許さない(エラー)。
- 初期値は不定。

## 5. 文

```
stmt = "var" ident ";"
     | ident "=" expr ";"
     | "if" "(" expr ")" block [ "else" ( block | ifstmt ) ]
     | "while" "(" expr ")" block
     | "return" [ expr ] ";"
     | "break" ";"
     | expr ";"
block = "{" { stmt } "}"
```

- `if` / `while` の本体は必ず `{ }` で囲む。
- `else if` は `else` の直後に `if` 文を置く形で書ける。
- `break` は直近の `while` を抜ける。`while` の外ではエラー。
- `continue` は無い(必要なら条件分岐で書く)。

## 6. 式

### 6.1 優先順位(低 → 高)

| 優先 | 演算子 | 結合 |
|---|---|---|
| 1 | `\|\|` | 左 |
| 2 | `&&` | 左 |
| 3 | `==` `!=` | 左 |
| 4 | `<` `<=` `>` `>=` | 左 |
| 5 | `\|` | 左 |
| 6 | `^` | 左 |
| 7 | `&` | 左 |
| 8 | `<<` `>>` | 左 |
| 9 | `+` `-` | 左 |
| 10 | `*` `/` `%` | 左 |
| 11 | 単項 `-` `!` `~` | 右 |
| 12 | 関数呼び出し `f(...)`、括弧 | - |

**注意:** C と異なり、ビット演算(`& ^ |`)は比較演算より**強く**結合する。
`(x & 1) == 0` の括弧は不要で、`x & 1 == 0` は `(x & 1) == 0` と解釈される。

### 6.2 意味

- `/` は 0 方向への切り捨て符号付き除算、`%` はその剰余。0 除算の動作は未定義(実装はトラップしてよい)。
- `>>` は算術右シフト、`<<` は論理左シフト。シフト量は 0〜63 のみ有効(範囲外は未定義)。
- `&&` `||` は短絡評価。
- 引数の評価順は**左から右**。
- 代入は文であり、式ではない。
- 式文は呼び出しの副作用のためのもの。

## 7. 組み込み関数

組み込みは次の 8 個のみ。識別子として予約され、機械語に直接展開される。

| 関数 | 動作 |
|---|---|
| `peek(a)` | アドレス `a` の 1 バイトを 0〜255 として返す |
| `poke(a, v)` | アドレス `a` に `v` の下位 8 ビットを書く。`0` を返す |
| `peekw(a)` | アドレス `a` の 8 バイトを word として返す |
| `pokew(a, v)` | アドレス `a` に `v` を 8 バイトで書く。`0` を返す |
| `getc()` | 標準入力から 1 バイト読む。EOF なら `-1` |
| `putc(c)` | 標準出力へ `c` の下位 8 ビットを書く。`0` を返す |
| `eputc(c)` | 標準エラー出力へ書く。`0` を返す |
| `exit(n)` | プロセスを終了コード `n` で終了する(戻らない) |

- 無効なアドレスへのアクセスは未定義(通常は SIGSEGV)。
- 構造体や配列は存在しない。データ構造は `peekw` / `pokew` とアドレス計算で作る。

```
# 例: 8 バイト要素の配列 tab の i 番目
var tab[8000];
fn get(i) { return peekw(tab + i * 8); }
fn set(i, v) { pokew(tab + i * 8, v); return 0; }
```

## 8. 文法(EBNF)

```
program  = { global | func } ;
global   = "var" ident [ "[" int "]" ] ";" ;
func     = "fn" ident "(" [ ident { "," ident } ] ")" block ;

block    = "{" { stmt } "}" ;
stmt     = "var" ident ";"
         | ident "=" expr ";"
         | "if" "(" expr ")" block [ "else" ( block | stmt_if ) ]
         | "while" "(" expr ")" block
         | "return" [ expr ] ";"
         | "break" ";"
         | expr ";" ;
stmt_if  = "if" "(" expr ")" block [ "else" ( block | stmt_if ) ] ;

expr     = or ;
or       = and { "||" and } ;
and      = eq  { "&&" eq } ;
eq       = rel { ( "==" | "!=" ) rel } ;
rel      = bor { ( "<" | "<=" | ">" | ">=" ) bor } ;
bor      = bxor { "|" bxor } ;
bxor     = band { "^" band } ;
band     = shift { "&" shift } ;
shift    = add { ( "<<" | ">>" ) add } ;
add      = mul { ( "+" | "-" ) mul } ;
mul      = unary { ( "*" | "/" | "%" ) unary } ;
unary    = ( "-" | "!" | "~" ) unary | primary ;
primary  = int | char | string | ident
         | ident "(" [ expr { "," expr } ] ")"
         | "(" expr ")" ;
```

LL(1) で、1 トークン先読みの再帰下降パーサで実装できる(`ident` の直後が `(` かどうかで呼び出しか変数かを区別する)。

## 9. エラー

コンパイルエラーは標準エラー出力に `line N: メッセージ` を出し、終了コード 1 で終了する。
最低限検出するもの:

- 構文エラー
- 未宣言の識別子・関数
- 再宣言・再定義
- 引数個数の不一致(組み込み含む)
- 配列グローバルへの代入
- `while` 外の `break`
- `main` の欠落

## 10. 実行モデル

### 10.1 ABI(呼び出し規約)

- 引数は**左から右の順にスタックへ push**し(評価順と一致)、呼び出し側が戻り後に回収する。
- 戻り値は `rax`。
- フレーム: `push rbp; mov rbp, rsp; sub rsp, 8*L`(L はローカル数)。
  - n 個の引数を持つ関数の第 i 引数(0 始まり)は `[rbp + 16 + 8*(n-1-i)]`
  - 第 k ローカル(0 始まり)は `[rbp - 8*(k+1)]`
- `L` は関数の終端まで確定しないため、`sub rsp, imm32` は**バックパッチ**する。

### 10.2 式の評価(スタックマシン方式)

- すべての式は結果を `rax` に残す。
- 二項演算: 左辺を評価して `push rax` → 右辺を評価 → `mov rcx, rax; pop rax` → 演算。
- レジスタ割り当ては行わない。

### 10.3 プログラム起動

`_start` は `main` を呼び、戻り値を引数に `exit` システムコールを発行する。

### 10.4 システムコール(Linux x86-64)

| 組み込み | syscall |
|---|---|
| `getc` | `read(0, buf, 1)`(1 バイトをスタック上に確保) |
| `putc` | `write(1, buf, 1)` |
| `eputc` | `write(2, buf, 1)` |
| `exit` | `exit(n)` |

## 11. 出力形式(ELF)

単一の `PT_LOAD`(RWX)セグメントだけを持つ静的 ELF64。

```
オフセット 0    ELF ヘッダ (64 バイト)
オフセット 64   プログラムヘッダ x1 (56 バイト)
オフセット 120  コード → 文字列データ
...             (ファイルには含まれない) グローバル領域は p_memsz > p_filesz で確保
```

- ロードアドレス: `0x400000`(`p_vaddr = 0x400000`、エントリ = `0x400078`)
- グローバル領域(`var`)はファイル末尾以降の BSS として、ロード時にゼロ初期化される。
- コンパイラは出力全体をメモリ上にバッファし、サイズと各アドレスを確定してから標準出力へ書き出す。
- 実行ビットはコンパイラでは付与しない(`chmod +x` で付ける)。

## 12. コンパイラの使い方

```
ouroc < prog.ou > prog
chmod +x prog
./prog
```

入力は標準入力、出力は標準出力(ELF バイナリ)、診断は標準エラー出力。

## 13. セルフホストの手順

| 段階 | 内容 |
|---|---|
| stage0 | C(約 500〜800 行)で書いた `ouroc0`。Ouro のブートストラップ専用 |
| stage1 | Ouro で書いた `ouroc.ou`。`ouroc0 < ouroc.ou > ouroc1` |
| stage2 | `ouroc1 < ouroc.ou > ouroc2` |
| 検証 | `cmp ouroc1 ouroc2` が一致すれば**固定点に到達** = セルフホスト成功 |

固定点に達したら stage0 は不要になる。以後は `ouroc` のみで `ouroc` を再生成できる。

### 13.1 ブートストラップの前提

- コンパイラの出力は**決定的**であること(ハッシュ順序、時刻、アドレスなどに依存しない)。
- `ouroc.ou` は本仕様の機能のみを使うこと(stage0 が処理できる範囲を超えない)。

## 15. サンプル

### 15.1 Hello, world

```
fn puts(s) {
  while (peek(s)) { putc(peek(s)); s = s + 1; }
  return 0;
}
fn main() { puts("Hello, Ouro!\n"); return 0; }
```

### 15.2 最大公約数

```
fn gcd(a, b) {
  while (b) { var t; t = b; b = a % b; a = t; }
  return a;
}
fn main() { putc('0' + gcd(12, 18)); putc('\n'); return 0; }
```

### 15.3 数値の 10 進出力

```
var nbuf[24];
fn putnum(n) {
  var i;
  if (n == 0) { putc('0'); return 0; }
  if (n < 0) { putc('-'); n = 0 - n; }
  i = 0;
  while (n) { poke(nbuf + i, '0' + n % 10); n = n / 10; i = i + 1; }
  while (i) { i = i - 1; putc(peek(nbuf + i)); }
  return 0;
}
```

### 15.4 字句解析器の断片(コンパイラ自身で使う形)

```
var src[262144];
var srclen;
var pos;

fn read_all() {
  var c;
  c = getc();
  while (c != 0 - 1) { poke(src + srclen, c); srclen = srclen + 1; c = getc(); }
  return srclen;
}
fn is_digit(c) { return c >= '0' && c <= '9'; }
fn is_alpha(c) { return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || c == '_'; }
```

## 16. 適合テスト(最小)

1. 15 章のサンプルがすべて期待どおりに動く。
2. 再帰(フィボナッチ、アッカーマン)が正しく動く。
3. 各演算子の優先順位・結合性テスト(特に `&` と `==` の関係)。
4. 短絡評価: `0 && f()` で `f` が呼ばれない。
5. §9 の各エラーが検出される。
6. **固定点テスト**: §13 の `cmp ouroc1 ouroc2` が一致する。
